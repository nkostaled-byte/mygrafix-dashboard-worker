# Aurelia Restaurant

A modern, premium restaurant website built with React, TypeScript, Vite, and Tailwind CSS.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- Lucide React

## Features

- Responsive design
- Luxury restaurant UI
- Interactive menu
- Gallery
- Online reservations
- Contact form
- Smooth animations
- SEO friendly
- Reusable component architecture

## Getting Started

Clone the repository:

```bash
git clone https://github.com/<your-username>/aurelia-restaurant.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
